OBJETIVO DA ATIVIDADE
Implementar o Padrão de Projeto Abstract Factory para criar famílias de objetos relacionados (lanches vegetarianos e não vegetarianos), permitindo que o sistema possa criar produtos relacionados sem especificar suas classes concretas, seguindo as definições do GoF (Gang of Four).

*INSTRUÇÕES TÉCNICAS*

PRÉ-REQUISITOS:
-Java Development Kit (JDK) versão 8 ou superior
-Terminal/Prompt de comando

*PROCEDIMENTOS DE COMPILAÇÃO*
Acesse o diretório do projeto:

cd Atividade3Alexandre_Malavazi/src
Compile todos os arquivos fonte:

javac *.java
Execute a aplicação:

java Cliente
