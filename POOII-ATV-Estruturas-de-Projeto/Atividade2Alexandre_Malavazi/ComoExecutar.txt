OBJETIVO DA ATIVIDADE
Implementar o Padrão de Projeto Adapter para adaptar o uso de um controle de Playstation para um controle de Xbox, permitindo que um sistema projetado para Xbox possa utilizar controles de Playstation através de um adaptador. O padrão demonstra a conversão de interfaces incompatíveis, seguindo as definições do GoF (Gang of Four).

*INSTRUÇÕES TÉCNICAS*

PRÉ-REQUISITOS:
-Java Development Kit (JDK) versão 8 ou superior
-Terminal/Prompt de comando

*PROCEDIMENTOS DE COMPILAÇÃO*
Acesse o diretório do projeto:


cd Atividade2Alexandre_Malavazi/src
Compile todos os arquivos fonte:

javac *.java
Execute a aplicação:

java Cliente
ESTRUTURA DE ARQUIVOS

├── ControlePlaystation.java                   (Classe adaptee)
