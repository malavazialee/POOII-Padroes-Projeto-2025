OBJETIVO DA ATIVIDADE
Implementar o Padrão de Projeto Factory Method para simular uma pizzaria que fabrica diferentes sabores de pizza (Portuguesa, Calabresa, Marguerita, QuatroQueijos), demonstrando o conceito de Virtual Constructor conforme definido pelo GoF.

*INSTRUÇÕES TÉCNICAS*

PRÉ-REQUISITOS:
-Java Development Kit (JDK) versão 8 ou superior
-Terminal/Prompt de comando

*PROCEDIMENTOS DE COMPILAÇÃO*
Acesse o diretório do projeto:

cd Atividade1AlexandreMalavazi/src
Compile todos os arquivos fonte:

javac *.java
Execute a aplicação:

bash
java Cliente
